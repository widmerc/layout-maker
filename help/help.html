Layout Maker

QGIS-Plugin für Falzmarken und Pläne mit Plankopf

QGIS plugin for fold marks and plans with a title block

Plugin QGIS pour les marques de pliage et les plans avec cartouche

Überblick

Layout Maker hat zwei Funktionen, erreichbar über den Hauptdialog (Symbolleiste oder Menü Layout Maker):

① FalzmarkenFalzmarken auf einem bestehenden Print-Layout setzen oder entfernen.
② Plan erstellenEinen neuen Plan erzeugen – per Kartenausschnitt oder mit vordefinierter Grösse, optional mit Plankopf.

Overview

Layout Maker has two features, reachable from the main dialog (toolbar or Layout Maker menu):

① Fold marksSet or remove fold marks on an existing print layout.
② Create planBuild a new plan – by drawing a map extent or with a predefined size, optionally with a title block.

Aperçu

Layout Maker propose deux fonctions, accessibles depuis la boîte de dialogue principale (barre d'outils ou menu Layout Maker) :

① Marques de pliageAjouter ou supprimer les marques de pliage sur une mise en page existante.
② Créer un planCréer un nouveau plan – en dessinant une emprise ou avec une taille prédéfinie, avec cartouche en option.

1 Falzmarken

Falzmarken sind kurze Strichmarkierungen am Rand eines Plans, verteilt nach einem festen Raster (Standard A4, 210 × 297 mm) – sie zeigen, wo ein grosses Blatt gefaltet werden muss, damit es z. B. in einen Bundordner passt. Das Rastermass lässt sich unter dem ⚙ Einstellungen-Symbol im Hauptdialog anpassen (z. B. auf A3). Das Ziel-Layout muss bereits im Projekt existieren.

1 Fold marks

Fold marks are short tick marks along the edge of a plan, spaced to a fixed grid (default A4, 210 × 297 mm) – they show where a large sheet must be folded, e.g. to fit into a binder. The grid size can be changed under the ⚙ Settings icon in the main dialog (e.g. to A3). The target layout must already exist in the project.

1 Marques de pliage

Les marques de pliage sont de courts traits de repère le long du bord d'un plan, espacés selon une grille fixe (par défaut A4, 210 × 297 mm) – ils indiquent où plier une grande feuille, p. ex. pour un classeur. La taille de la grille peut être modifiée sous l'icône ⚙ Paramètres dans la boîte de dialogue principale (p. ex. en A3). La mise en page cible doit déjà exister dans le projet.

Raster (gestrichelt) + Falzmarken (kurze Striche an den Kanten) Grid (dashed) + fold marks (short ticks on the edges) Grille (pointillés) + marques de pliage (courts traits sur les bords)
Falzmarken hinzufügen …Öffnet den Dialog mit allen Parametern (Markenlänge, Strichstärke, Rahmen, Plankopf-Position); bestätigt wird mit Falzmarken setzen. Alte fm_*-Marken können vorher automatisch gelöscht werden.
Falzmarken entfernen …Einfacher Dialog: nur Ziel-Layout wählen und bestätigen – entfernt alle vorhandenen Falzmarken (fm_*-Objekte), ohne neue zu setzen.
Add fold marks …Opens the dialog with all parameters (mark length, line width, border, title block position); confirmed with Set fold marks. Existing fm_* marks can be deleted first automatically.
Remove fold marks …Simple dialog: just pick the target layout and confirm – removes all existing fold marks (fm_* objects), without drawing new ones.
Ajouter des marques de pliage …Ouvre la boîte de dialogue avec tous les paramètres (longueur des marques, épaisseur du trait, cadre, position du cartouche) ; confirmé avec Ajouter les marques de pliage. Les marques fm_* existantes peuvent être supprimées au préalable automatiquement.
Supprimer les marques de pliage …Boîte de dialogue simple : choisissez la mise en page cible et confirmez – supprime toutes les marques de pliage existantes (objets fm_*), sans en dessiner de nouvelles.

2 Der Plankopf

Der Plankopf ist nur das Kopf-/Stempelfeld einer Vorlage (.qpt) – Logo, Massstab, Projektangaben usw. Er enthält keine eigene Karte. Er belegt eine Spalte an der linken oder rechten Seite der Seite (über die volle Höhe reserviert); die Kartenfläche füllt automatisch die jeweils andere Spalte.

links / rechts in der Plankopf-Position wählt die Spalte. oben / unten bestimmt, wie der Plankopf-Inhalt innerhalb dieser Spalte ausgerichtet wird – füllt er die Spalte nicht ganz aus, bleibt der Rest davon leer (kein Karteninhalt rutscht dort hinein).

2 The title block

The title block is only the header/stamp field of a template (.qpt) – logo, scale, project details, etc. It contains no map of its own. It occupies a column on the left or right side of the page (reserved for the full page height); the map area automatically fills the other column.

left / right in the title block position chooses the column. top / bottom determines how the title block content is aligned within that column – if it doesn't fill the whole column, the rest of it stays blank (the map does not flow into it).

2 Le cartouche

Le cartouche est uniquement l'en-tête/le tampon d'un modèle (.qpt) – logo, échelle, informations du projet, etc. Il ne contient pas de carte propre. Il occupe une colonne à gauche ou à droite de la page (réservée sur toute la hauteur) ; la zone cartographique remplit automatiquement l'autre colonne.

gauche / droite dans la position du cartouche choisit la colonne. haut / bas détermine comment le contenu du cartouche est aligné dans cette colonne – s'il ne la remplit pas entièrement, le reste demeure vide (la carte n'y déborde pas).

Beispiel oben links: Plankopf-Position „oben links" → linke Spalte, Inhalt oben ausgerichtet; die Karte füllt die rechte Spalte über die volle Höhe.

Example top-left: title block position "top left" → left column, content aligned to the top; the map fills the right column over the full height.

Exemple en haut à gauche : position du cartouche « en haut à gauche » → colonne de gauche, contenu aligné en haut ; la carte remplit la colonne de droite sur toute la hauteur.

Plankopf-Vorlage (.qpt) erstellen

Damit die Platzierung korrekt funktioniert, muss die .qpt-Datei nur die Plankopf-Elemente enthalten (kein Kartenrahmen, kein Seitenhintergrund):

  1. Print-Layout in QGIS öffnen (oder neu erstellen) und die Plankopf-Elemente (Logo, Textfelder, Tabelle usw.) bauen bzw. platzieren.
  2. Wichtig: Diese Elemente möglichst nahe an die Ecke oben links der Seite setzen (nicht mittig oder mit grossem Abstand zum Seitenrand) – der Plugin berechnet die Spaltenbreite/-höhe aus der Bounding Box dieser Elemente. Ist viel Leerraum um die Elemente herum, wird die reservierte Spalte unnötig gross.
  3. Alle Plankopf-Elemente mit der Maus markieren (Kartenrahmen/Hintergrundrechteck nicht mit auswählen).
  4. Rechtsklick → „Ausgewählte Elemente als Vorlage speichern…" (nicht „Layout als Vorlage speichern" – das würde die ganze Seite inkl. Grösse mit abspeichern).
  5. Die gespeicherte .qpt-Datei im Dialog „Plan erstellen" unter „Plankopf-Vorlage" auswählen.

Tipp: Enthält die Vorlage projektspezifische Textfelder (z. B. Titel, Massstab), können diese als QGIS-Ausdrücke/Layoutvariablen eingesetzt werden, die das Plugin beim Erstellen automatisch befüllt (Titel, Massstab).

Building a title block template (.qpt)

For the placement to work correctly, the .qpt file must contain only the title block elements (no map frame, no page background):

  1. Open (or create) a print layout in QGIS and build/place the title block elements (logo, text fields, table, etc.).
  2. Important: position these elements as close as possible to the top-left corner of the page (not centred or with a large gap to the page edge) – the plugin calculates the column width/height from the bounding box of these elements. Lots of empty space around them makes the reserved column unnecessarily large.
  3. Select all title block elements with the mouse (do not include the map frame/background rectangle).
  4. Right-click → "Save Selected Items as Template…" (not "Save Layout as Template" – that would also save the whole page including its size).
  5. Pick the saved .qpt file under "Title block template" in the "Create plan" dialog.

Tip: if the template contains project-specific text fields (e.g. title, scale), these can use QGIS expressions/layout variables that the plugin fills in automatically when creating the plan (Titel, Massstab).

Créer un modèle de cartouche (.qpt)

Pour que le placement fonctionne correctement, le fichier .qpt doit contenir uniquement les éléments du cartouche (pas de cadre de carte, pas d'arrière-plan de page) :

  1. Ouvrez (ou créez) une mise en page dans QGIS et construisez/placez les éléments du cartouche (logo, champs de texte, tableau, etc.).
  2. Important : placez ces éléments le plus près possible du coin supérieur gauche de la page (pas centrés ni avec un grand espace par rapport au bord) – le plugin calcule la largeur/hauteur de la colonne à partir de la boîte englobante de ces éléments. Un grand espace vide autour d'eux rend la colonne réservée inutilement grande.
  3. Sélectionnez tous les éléments du cartouche avec la souris (sans inclure le cadre de carte/rectangle d'arrière-plan).
  4. Clic droit → « Enregistrer les éléments sélectionnés comme modèle… » (pas « Enregistrer la mise en page comme modèle », qui sauvegarderait aussi toute la page, taille comprise).
  5. Choisissez le fichier .qpt enregistré sous « Modèle de cartouche » dans la boîte de dialogue « Créer un plan ».

Astuce : si le modèle contient des champs de texte spécifiques au projet (p. ex. titre, échelle), ceux-ci peuvent utiliser des expressions QGIS/variables de mise en page que le plugin remplit automatiquement lors de la création (Titel, Massstab).

3 Plan erstellen

Baut ein komplett neues Layout. Die Kartenfläche kommt auf einem von zwei Wegen zustande:

Ausschnitt aufziehenAuf der Karte ein Rechteck aufziehen (oder den aktuellen Ausschnitt übernehmen) und einen Massstab eingeben – die Plangrösse wird daraus berechnet.
Vordefinierte PlangrösseEin Papierformat (A0–A4 oder benutzerdefiniert, Hoch-/Querformat) und einen Massstab wählen. Der Kartenausschnitt wird automatisch zentriert auf den Mittelpunkt des aktuell sichtbaren Kartenausschnitts berechnet.

In beiden Fällen ist der Plankopf optional (siehe oben), und Falzmarken/Rahmen werden automatisch mit dem gewählten Parametern hinzugefügt.

3 Create plan

Builds a completely new layout. The map area is determined in one of two ways:

Draw extentDraw a rectangle on the map (or use the current extent) and enter a scale – the plan size is calculated from that.
Predefined plan sizeChoose a paper format (A0–A4 or custom, portrait/landscape) and a scale. The map extent is calculated automatically, centred on the middle of the currently visible map view.

In both cases the title block is optional (see above), and fold marks/border are added automatically with the chosen parameters.

3 Créer un plan

Crée une toute nouvelle mise en page. La zone cartographique est déterminée de deux façons :

Dessiner l'empriseDessinez un rectangle sur la carte (ou reprenez l'emprise actuelle) et indiquez une échelle – la taille du plan en est déduite.
Taille de plan prédéfinieChoisissez un format de papier (A0–A4 ou personnalisé, portrait/paysage) et une échelle. L'emprise de la carte est calculée automatiquement, centrée sur le milieu de la vue actuellement visible.

Dans les deux cas, le cartouche est facultatif (voir ci-dessus), et les marques de pliage/le cadre sont ajoutés automatiquement selon les paramètres choisis.

  • Les noms de mise en page doivent être uniques dans le projet.
