about=Layout Maker speeds up everyday QGIS print layout work for surveyors, planners and GIS professionals.

 Features:
 - Fold marks: add or remove folding marks on any print layout, grid size configurable (A4, A3, A2, A1, A0, custom)
 - Title block (Plankopf/cartouche): attach a title block template to any corner of a new plan; the map area fills the rest of the page automatically
 - Two ways to create a plan: draw a map extent on the canvas, or pick a predefined paper size
 - Multi-language interface: German, English, French
 - Works in both QGIS 3.x (Qt5) and QGIS 4.x (Qt6)
 - Built-in help page with diagrams, reachable from the plugin dialog

 Ideal for producing consistent, print-ready site plans and technical drawings (Situationspläne).
